# PTT Solutions – site update

Redesigned single-page site for PTT Solutions Limited (two-way radio equipment, Burnham-On-Crouch).

- `index.html` – the whole site in one self-contained file (CSS, JS and photos inlined). Open it in a browser or host it as-is.
- Black and champagne-gold design built around the original site's photos and copy.
- Apple-style scroll: pinned hero, word-by-word statement, pinned services, horizontal sector gallery, count-up figures.
- Falls back to a normal scrolling layout on phones and with "reduce motion" turned on.

## Before going live
- Enquiry forms open the visitor's email app (`mailto:`). Connect a form service or backend for real submissions.
- Shop shows a selection of products with enquiry buttons; checkout needs a shop platform.
- Raleway loads from Google Fonts when online.
